# Provenance and validation records

The current distribution and import identity is `openbacktesting`, version `0.2.0`. Read this manual as Markdown or build the documentation site with `uv run --locked --group docs mkdocs build --strict`. The generated HTML, navigation, and search index are written to `build/docs/` and are not committed.

See the [extraction manifest](../../extraction-manifest.json) for the direct source snapshot, file mappings, and digests, and the [historical source manifest](../../source-manifest.json) for earlier upstream provenance. Source paths are normalized to the new identity; source digests represent original bytes, while target digests represent migrated files.

See the [validation record](extraction-verification.md) for this implementation's environment, commands, and results, and [development](development.md) for build and independent acceptance commands.
