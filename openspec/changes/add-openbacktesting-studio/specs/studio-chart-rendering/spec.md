## Purpose

定义框架完整图表数据在 Studio 中的可观察语义，确保行情、指标、面板、颜色、事件与真实成交能准确呈现，时间精度和计算因果关系不被渲染破坏，缩放及聚合始终只是同一次运行的视图。

## ADDED Requirements

### Requirement: 主图与副图共享正确横轴

Studio MUST 展示 OHLC 主图、可用成交量及策略声明的全部面板，保持各自纵轴和声明关系。多面板与独立权益图 MUST 使用可追溯的原始横轴映射联动，不因序列长度或采样等级不同错位。

#### Scenario: 指标开始前存在无效数据

- **WHEN** 指标前部存在缺失而行情完整
- **THEN** 指标仍与对应原始 K 线对齐，不能从第一个有效值重新编号

#### Scenario: 不同图表的聚合等级不同

- **WHEN** 行情图和权益图显示不同采样密度
- **THEN** 可见范围与光标按原始 bar 或时间身份同步，不直接复制不兼容的 logical index

### Requirement: 精确时间与非时间轴

渲染 MUST 保留原始 bar 身份和纳秒精度，显式区分 UTC 纳秒、无时区日期时间和 ordinal。转换后碰撞 MUST 通过自定义轴或源码能力支持，不能合并原本不同的 K 线；ordinal MUST 不伪造日期，naive 时间 MUST 不擅自解释为 UTC。

#### Scenario: 两根 K 线落在同一秒

- **WHEN** 原始时间轴有不同纳秒标签但原生秒坐标不足以区分
- **THEN** 图表仍能独立选择两根 K 线并显示原始时间，不能覆盖其中一根

#### Scenario: 显示时区跨夏令时边界

- **WHEN** 用户改变图表展示时区
- **THEN** 只更新标签，不改变 UTC 顺序、事件归属或回测指标

### Requirement: 所有连续图形保持声明语义

图表 MUST 实现 line、step、histogram、level 和 fill，保留颜色、alpha、基线、面板及兼容边界。有效性、就绪状态、gap 和 offset MUST 影响展示但不改变计算事实。

#### Scenario: 断线与连接缺口

- **WHEN** 同样的缺失数据分别使用 `break` 和 `connect`
- **THEN** 前者真正断开，后者只连接允许连接的有效点；两者均不把缺失解释为零

#### Scenario: 区间边界交叉

- **WHEN** 两条填充边界发生交叉或其中一条出现缺口
- **THEN** 填充仍遵循两边界与 gap 规则，不变为对底部的错误面积填充

#### Scenario: 正向展示偏移

- **WHEN** 声明 `offset_bars` 大于零
- **THEN** 图形按 K 线位置移动并保留必要展示槽位，原成交和指标获知时间不变

### Requirement: 每根颜色事件独立生效

蜡烛颜色 MUST 同时作用于烛身、影线与边框；背景颜色 MUST 作用于指定 pane 和 K 线。事件按顺序最后写入生效，None 清除当前覆盖，透明颜色不得误当作未设置，颜色不能自动跨 K 线继承。

#### Scenario: 同根写入颜色后清除

- **WHEN** 策略在同一根 K 线上先设置再清除颜色
- **THEN** 该根恢复默认颜色，其他 K 线与 pane 不受影响

### Requirement: 策略标记与实际成交分离

图表 MUST 实现全部声明标记形状、文字和价格定位，保留 `anchorBar` 与 `knownAtBar`。真实成交 MUST 使用事实 ID、价格和方向，策略信号不能被显示成已成交；同一时刻多次成交必须可分别查看。

#### Scenario: 信号下一根才成交

- **WHEN** 策略标记在当前根但真实 fill 在下一根
- **THEN** 两者各自在正确位置显示，图例和详情明确区别

#### Scenario: 回标历史事件

- **WHEN** 某事件现在确认但 anchor 指向更早的 K 线
- **THEN** 图形位于 anchor，详情同时展示确认时机，不暗示当时已知

#### Scenario: 同根多次成交

- **WHEN** 多个 fill 共享同一时间或价格
- **THEN** 可通过命中选择或聚合详情访问每个真实 fill ID，不丢弃重复时间事件

### Requirement: 自动范围与选择基于有效事实

纵轴缩放 MUST 基于当前可见范围内有效数据并考虑相关基线和水平线，不以缺失或未来不可用点污染范围。交易定位、光标和参数拾取 MUST 反查准确原始值，不把聚合代表值当成真实成交。

#### Scenario: 用户点击交易表的一次成交

- **WHEN** 表格请求定位某个 fill ID
- **THEN** 图表定位并突出该 fill，而不是同时间的其他成交

### Requirement: 聚合只影响展示

显示缩放、范围读取和降采样 MUST 不重新执行策略或改变报告数值。聚合 MUST 保留原始范围和身份，披露显示粒度；OHLCV、指标、权益和离散事件必须按各自语义处理，不能通用平均。

#### Scenario: 放大聚合区间

- **WHEN** 用户从聚合视图放大到原始粒度
- **THEN** 能恢复原始数据与事件详情，摘要指标始终不变

#### Scenario: 慢旧请求后返回

- **WHEN** 用户已切换范围但旧图表响应随后到达
- **THEN** 旧响应不覆盖新视口或新运行的图形

### Requirement: 特性兼容错误不可伪装完整

当前框架全部必需绘图特性 MUST 实现。未来未知 schema 主版本或 requiredFeatures MUST 返回明确兼容性状态，不能静默忽略；缺少图表时有效 Portfolio MUST 仍可读取。

#### Scenario: 导入未来必需特性

- **WHEN** PlottingResult 声明客户端无法理解的必需特性
- **THEN** 图表显示不兼容说明，不能标为完整渲染，也不阻止独立报告读取
