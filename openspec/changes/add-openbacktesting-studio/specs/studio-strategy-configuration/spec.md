## Purpose

定义策略发现、类型化参数表单、执行属性和数据配置的统一行为，使 UI 严格遵循框架已有的 schema 与单位，避免参数编辑隐式改变源码或数据，并支持可检查的预设与配置变更。

## ADDED Requirements

### Requirement: 使用公开策略发现契约

Studio MUST 基于固定源码加载并调用公开运行时描述接口，保持恰好一个直接装饰的具体策略入口约束；发现 MUST 不执行策略生命周期，但导入异常须可诊断。界面 MUST 不猜测选择多个候选，也不靠实例化策略获取参数。

#### Scenario: 多个入口

- **WHEN** 当前模块包含多个有效装饰策略
- **THEN** 发现失败并列出候选，不能静默选第一个

#### Scenario: 无参数策略

- **WHEN** 策略有有效入口但没有声明 inputs
- **THEN** 展示明确的无参数状态，仍可设置执行属性和运行

### Requirement: 全部输入类型与编码保持一致

表单 MUST 支持 `int/float/bool/string/price/time/session/color/enum`。提交 MUST 使用框架规定的标题键和序列化值，保留单位、枚举成员名与颜色透明度。无效值 MUST 在运行前被拒绝，以框架校验为最终依据。

#### Scenario: 数值编辑存在中间空值

- **WHEN** 用户清空数值字段或输入无穷值
- **THEN** 保留可编辑草稿并阻止提交，不能偷偷转换为零或默认值

#### Scenario: 时间与颜色提交

- **WHEN** 用户确认时间和半透明颜色
- **THEN** 时间按 Unix 毫秒提交，颜色保留 alpha，不因显示时区或控件格式丢失原意

#### Scenario: 数字选项与步长

- **WHEN** schema 提供 options 或 step
- **THEN** options 限制合法选项，step 仅作为调整增量，UI 不增加框架没有的整除规则

### Requirement: 展示元信息与参数有效性分离

表单 MUST 保留声明顺序、group、inline、tooltip、active 和 confirm 语义。`display=none` MUST 不隐藏设置控件；禁用字段 MUST 保留值并参与框架校验。价格和时间确认 MUST 支持回填草稿，不自动运行。

#### Scenario: 依赖开关关闭

- **WHEN** 某字段的 active 依赖变为 false
- **THEN** 字段变为不可编辑但值不丢失，重新启用后恢复原值

#### Scenario: 布尔和颜色默认不展示于状态栏

- **WHEN** 对应输入具有 `display=none`
- **THEN** 输入仍显示在设置表单，可正常修改

#### Scenario: 图上选择价格或时间

- **WHEN** 用户进入确认拾取模式并选择图表位置
- **THEN** 对应 price／time 草稿被更新，用户确认运行前不产生新回测

### Requirement: 预设绑定参数 schema

预设 MUST 保存 schema 版本、哈希和标题键覆盖值。schema 改变时 MUST 阻止旧请求自动运行，显示字段匹配与失效原因，由用户确认形成新请求。重置默认值 MUST 使用当前定义，不改变源码。

#### Scenario: 输入标题或类型改变

- **WHEN** 重新发现后保存的预设不再匹配
- **THEN** 提示 schema 过期及差异，不能根据相似名称静默迁移

### Requirement: 执行属性与策略参数分开

执行属性 MUST 单独展示，使用框架声明默认值和稀疏覆盖规则，明确显示金额、比例、百分点、bps 和价格距离单位。改变成对的类型与数值 MUST 一起校验，不能把展示样式当作执行参数。

#### Scenario: 修改佣金类型

- **WHEN** 用户从百分比佣金改为每笔固定费用
- **THEN** UI 显示对应单位，并提交完整类型与值，不能沿用未确认的异单位数值

### Requirement: 数据来源与运行上下文显式

Studio MUST 支持内置示例、本地 CSV 和明确注册的本地 loader，记录来源、列映射、时间语义、周期、时区、品种规则与范围。自定义列 MUST 保留并参与身份计算。数据不合法时 MUST 报错，不静默排序、去重、补值或修改价格以使运行通过。

#### Scenario: CSV 时间没有时区

- **WHEN** 数据时间字符串没有时区且配置没有说明源时区
- **THEN** 阻止运行并要求补充信息，不根据本机时区猜测

#### Scenario: 数据重复或乱序

- **WHEN** 行情存在重复时间或不满足框架排序规则
- **THEN** 显示数据错误并保留源数据，不自行去重或排序后假装原样执行

#### Scenario: 周期声明变化

- **WHEN** 用户修改回测周期
- **THEN** 要求匹配的数据配置并创建新运行，不能仅缩放已有图表冒充新周期回测

### Requirement: 运行使用实际数据快照

加载数据 MUST 在受管进程中完成，实际传给框架的数据、上下文和品种规则 MUST 固定并记录身份。入队时已捕获的本地来源文件后续变化不得改变该任务输入或已完成结果；loader 的未声明外部读取 MUST 标明非封闭来源。不支持的数据类型 MUST 明确拒绝，不能有损字符串化。

#### Scenario: 加载后替换 CSV

- **WHEN** 数据快照已固定而原 CSV 被替换
- **THEN** 该运行继续使用固定快照，后续运行才获取新数据并产生不同数据身份
