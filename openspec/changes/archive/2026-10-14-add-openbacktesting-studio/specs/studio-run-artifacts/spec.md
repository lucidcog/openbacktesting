## Purpose

定义与 Python 活对象解耦的 Studio 运行记录、数据产物和可交换结果容器，支持纯框架用户导入、无源码查看与可追溯重跑，并在损坏、缺失或版本不兼容时保留准确的可用性边界。

## ADDED Requirements

### Requirement: 公开结果保持原有结构

Studio MUST 保存公开 Portfolio 和 PlottingResult 的原始版本与结构，使用独立的 Studio 元数据关联它们，不能通过修改框架字段或重算统计统一模型。读取历史结果 MUST 不访问运行中的策略对象。

#### Scenario: 保存后修改返回字典

- **WHEN** 运行已保存而其他调用者修改内存中的导出副本
- **THEN** 已保存结果保持原事实，读取不会重新计算或运行策略

### Requirement: 运行来源可追溯

运行记录 MUST 包含源码与依赖身份、有效参数和设置、数据身份、时间上下文、品种规则、环境版本、范围和产物清单。声称可重跑时 MUST 有实际内容或可验证不可变引用，不能仅凭哈希声称可恢复。

#### Scenario: 只有源码哈希没有源码

- **WHEN** 导入记录只含代码摘要
- **THEN** 报告仍可读，但重新运行能力被明确标为不足，不能从当前同名文件补齐后冒充原版本

### Requirement: 保存完整性与损坏隔离

必要产物 MUST 在完整写入并通过大小／摘要检查后才发布。损坏、缺失和未提交临时文件 MUST 不被标为完整成功记录；一个运行损坏 MUST 不妨碍其他有效运行读取。

#### Scenario: 保存期间进程退出

- **WHEN** 写入目录只有部分 JSON 或未完成清单
- **THEN** 恢复过程识别其不完整状态，不把它列为完整可用报告

#### Scenario: 文件摘要不符

- **WHEN** 某个保存产物被外部修改
- **THEN** 读取返回明确损坏信息，不能继续使用不匹配内容计算展示结论

### Requirement: 容器支持选择性分享

系统 MUST 提供带清单、版本和摘要的结果容器导出。默认分享 MUST 不携带源码、原始数据和完整日志；用户显式选择后方可包含，并能在导出前了解范围和体积。会话密钥 MUST 永不导出。

#### Scenario: 默认导出运行

- **WHEN** 用户未勾选敏感或大体积的可选资源
- **THEN** 导出含可读报告、已有图表和必要元数据，不含完整源码与原始数据

### Requirement: 导入仅处理受限数据

导入 MUST 校验版本、摘要、文件名、路径和展开容量，拒绝危险归档条目与可执行反序列化。包内源码 MUST 只作为文本。未知必需主版本 MUST 拒绝，不能猜测转换。

#### Scenario: 归档条目逃逸或解压膨胀

- **WHEN** 容器含父目录路径、绝对路径、链接或超过展开上限
- **THEN** 导入安全失败，不能向目标范围外写文件，也不执行任何条目

#### Scenario: 未知容器主版本

- **WHEN** 读取不兼容版本
- **THEN** 保留原文件并给出兼容性说明，不覆盖或破坏数据

### Requirement: 纯框架结果可以独立查看

系统 MUST 接受独立 Portfolio JSON，并可接收配对 PlottingResult。只有报告时 MUST 提供可用报告，不能要求源码、Studio 原始运行索引或策略依赖。无法证明配对身份时 MUST 校验可比较事实并标注来源限制。

#### Scenario: 只导入 Portfolio

- **WHEN** 纯框架用户导入有效公开报告
- **THEN** 概要、交易和配置可读，图表缺失明确说明，不执行策略

#### Scenario: 两份结果内容不一致

- **WHEN** 用户手工配对的报告与图表在轴或成交事实方面冲突
- **THEN** 拒绝把它们作为同一可信运行联合展示，报告本身仍可单独读取

### Requirement: 重跑不覆盖历史

重跑 MUST 创建新 ID 并记录父运行关系，先校验所需代码、数据和环境。新运行失败 MUST 不改变原运行的报告；环境变化 MUST 明确披露。

#### Scenario: 查看优化试验报告

- **WHEN** 既有试验只保存了 Portfolio
- **THEN** 可以查看统计，但不宣称已有未保存的图表；补图需要显式的新运行及完整可用输入
