## Purpose

定义 Studio 对本地工作区、会话、文件系统和 Python 环境的访问边界，使本地 HTTP 服务能安全地区分用户操作与非授权请求，并明确可信 Python 执行和只读报告模式的限制。

## ADDED Requirements

### Requirement: 回环服务与有效会话

本地服务 MUST 默认只监听回环接口，并拒绝首版不支持的非回环绑定。所有数据、文件与运行 API MUST 校验当前会话；修改或执行请求 MUST 同时校验来源，不能用通配 CORS 或任意 Host 暴露本地能力。会话密钥 MUST NOT 出现在普通日志、持久化结果或 URL 查询参数中。

#### Scenario: 外部页面请求本地文件

- **WHEN** 不受信任的 Origin 或无效会话请求工作区内容或执行操作
- **THEN** 请求被拒绝，目标文件与进程状态均不改变

#### Scenario: 本地页面完成握手

- **WHEN** 使用启动入口的有效凭证建立会话
- **THEN** 客户端得到版本、模式和能力信息，后续操作受当前实例的会话边界约束

### Requirement: 明确的工作区路径范围

宿主 MUST 只操作指定工作区内被允许的普通文件。它 MUST 校验规范化后的真实路径，并拒绝绝对路径越界、父目录穿越、符号链接逃逸、设备文件及内部运行状态路径的编辑。

#### Scenario: 文件路径逃逸

- **WHEN** 客户端传入 `../` 路径或指向工作区外的符号链接
- **THEN** 操作返回路径拒绝错误，不能读取或写入外部目标

#### Scenario: 非文本或超限文件

- **WHEN** 请求编辑二进制、无法支持编码或超过编辑上限的文件
- **THEN** 显示明确限制，原文件内容保持不变

### Requirement: 用户代码不进入宿主进程

策略导入、参数发现、数据 loader 和回测执行 MUST 在受管独立进程中进行。HTTP 服务 MUST 不导入用户策略。产品 MUST 说明可信代码仍拥有当前用户权限，不能把进程边界宣称为操作系统沙箱。

#### Scenario: 模块导入时挂起

- **WHEN** 用户模块在顶层执行进入无限循环
- **THEN** 宿主仍可响应状态和取消请求，超时后可以回收该工作进程

### Requirement: 执行环境显式且可验证

宿主 MUST 探测选定解释器的 Python、框架和 worker 协议兼容性，并把实际环境记录到运行身份。它 MUST NOT 自动安装或升级用户环境，也不能在失败后悄然切换解释器。

#### Scenario: 项目环境缺少 worker 依赖

- **WHEN** 用户选择仅安装框架而缺少兼容 worker 能力的解释器
- **THEN** 发现和运行被阻止，并提供缺失依赖与目标解释器信息

### Requirement: 协议版本与可诊断错误

宿主 MUST 暴露协议版本和能力，拒绝不兼容请求。错误 MUST 有稳定类别、请求标识和可选字段错误，保留用户输入而不泄露密钥。分页和事件接口 MUST 提供可恢复的位置或明确过期状态。

#### Scenario: 客户端使用不支持的主版本

- **WHEN** 客户端协议与宿主不兼容
- **THEN** 返回明确兼容性错误，不继续猜测字段或执行请求

#### Scenario: 事件连接恢复

- **WHEN** 客户端携带最后事件序号重新连接
- **THEN** 获取未接收事件，或被告知历史已过期并重新读取权威运行状态

### Requirement: 只读模式不提供执行能力

只读查看器 MUST 不开放源码修改、发现或运行接口，不要求策略依赖，不因加载结果而执行其中的源码。服务关闭 MUST 释放受管资源并准确处理未结束运行。

#### Scenario: 导出包携带恶意源码

- **WHEN** 用户只读打开包含 Python 文本的结果包
- **THEN** 源码仅能作为文本查看，文件中的顶层代码不执行

### Requirement: 显式选择与记忆工作目录

Studio MUST 在首次没有记忆目录时先展示目录选择入口，不递归扫描或加载启动目录的文件。用户确认后 MUST 仅加载所选目录的文件和历史，并将规范路径保存到同源 localStorage。

#### Scenario: 选择目录后重新打开

- **WHEN** 用户选择目录，刷新页面或在相同来源重新启动服务
- **THEN** 从 localStorage 恢复该目录；路径不存在或不可读时提示重新选择，不退回扫描启动目录

#### Scenario: 切换工作区时保护正在进行的操作

- **WHEN** 用户请求切换目录
- **THEN** 未保存草稿或活动运行会阻止切换；宿主等待已接收的请求结束，旧标签页携带过期工作区身份的操作不能访问新目录
